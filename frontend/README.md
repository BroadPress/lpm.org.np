# Life Positive Mission (LPM) - Website

A modern, fully responsive website for Life Positive Mission, a volunteer-driven international non-profit organization.

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Pages Completed

| Page | Route |
|------|-------|
| Home | `/` |
| About | `/about` |
| Team | `/team` |
| Events | `/events` |
| FAQ | `/faq` |
| Gallery | `/gallery` |
| Contact | `/contact` |
| Join Now | `/join-now` |
| Donate | `/donate` |

## Key Features

- Collapsible sidebar (60px / 190px)
- Mobile bottom navigation
- Dark/Light mode toggle
- Dynamic page heroes with images
- Optimized images with lazy loading
- Fully responsive (mobile, tablet, desktop)
- Form validations (Contact, Join, Donate)
- Masonry gallery with lightbox
- Google Maps integration

## Getting Started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build

# Start production server
npm start
